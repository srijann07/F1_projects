# F1 Lap Analysis

A small Python data-analysis project for working with Formula 1 lap-time data.

## What it demonstrates

- Python scripting
- Reading and processing numerical data
- Basic performance calculations
- Simple, focused project structure

## Project files

- [`lap_average.py`](lap_average.py) — calculates an average lap-time value from the project data

## Run

```bash
python lap_average.py
```
